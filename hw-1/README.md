## JavaScript

Код разделен на ES-модули:

- `js/data.js` — массивы и объекты с данными;
- `js/ui.js` — создание и обновление DOM-элементов;
- `js/app.js` — обработчики кликов, ввода текста и отправки форм.

В приложении работают фильтры матчей, поиск команд и игроков, динамическая отрисовка таблиц и добавление матча в избранное.


## браузерное API

Используется **Local Storage API (Web Storage API)**. Избранные матчи сохраняются в браузере и восстанавливаются после перезагрузки или повторного открытия сайта. 

- `js/storage.js` — чтение, проверка и запись сохраненных данных через `getItem`, `setItem`, `removeItem`;
- `js/favorites.js` — управление избранным, обновление кнопок и синхронизация вкладок через событие `storage`;
- `js/ui.js` — создание строк матчей и кнопок;
- `js/app.js` — подключение модулей к страницам.


### Ошибки и запасной режим

- При отсутствии API, запрете доступа или ошибке чтения приложение продолжает работать и показывает сообщение.
- При ошибке записи, включая переполнение квоты, выбор продолжает работать в памяти текущей страницы. После перезагрузки он может потеряться.
- Некорректный JSON, неподходящая структура и неизвестная версия данных заменяются пустым списком с пояснением. Следующее успешное сохранение перезаписывает эти данные.
- Дубликаты и отсутствующие в приложении матчи исключаются из загруженного списка.
- Очистка удаляет только ключ `kickboard:favorites`, не затрагивая другие данные браузера.

### Проверки

Из корня репозитория:

```sh
node --test hw-1/tests/storage.test.mjs
```

Для проверки поврежденных данных в консоли браузера:

```js
localStorage.setItem("kickboard:favorites", "broken");
location.reload();
```

Появится сообщение об ошибке чтения. Затем добавьте матч заново.

Документация: [Web Storage API на MDN](https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API/Using_the_Web_Storage_API).

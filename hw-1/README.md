[OneSports — Football Dashboard в Figma](https://www.figma.com/design/InESBv49jdMrYiBWJNjzmK/OneSports---Football-Dashboard--Community-?node-id=0-1&p=f&t=yW4UB6YcXibWv5ZV-0)

Макет используется как визуальный референс. Структура и наполнение придуманы самостоятельно.

## JavaScript

Код разделён на ES-модули:

- `js/data.js` — массивы и объекты с данными;
- `js/ui.js` — создание и обновление DOM-элементов;
- `js/app.js` — обработчики кликов, ввода текста и отправки форм.

В приложении работают фильтры матчей, поиск команд и игроков, динамическая отрисовка таблиц и добавление матча в избранное.

Для запуска ES-модулей откройте проект через Live Server, а не двойным нажатием на HTML-файл.

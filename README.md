## Проект KickBoard

Футбольный дашборд для просмотра матчей, турнирной таблицы и статистики игроков.

В приложении пять связанных страниц:

- [Обзор](./hw-1/index.html) — главный экран, последние результаты, топ команд и избранные матчи.
- [Матчи](./hw-1/matches.html) — список игр с фильтрами «Вчера», «Сегодня», «Завтра» и «Все».
- [Турнирная таблица](./hw-1/standings.html) — положение команд и поиск по названию.
- [Центр матча](./hw-1/match.html) — счет, события, статистика и добавление в избранное.
- [Игроки](./hw-1/players.html) — карточки футболистов и поиск по имени или клубу.

Для просмотра самого приложения запустите проект локально по инструкции ниже.

### Дизайн

Визуальный референс — [OneSports — Football Dashboard в Figma](https://www.figma.com/design/InESBv49jdMrYiBWJNjzmK/OneSports---Football-Dashboard--Community-?node-id=0-1).


### Возможности JavaScript

- Создание и обновление карточек, строк таблицы и событий матча через DOM.
- Фильтрация матчей по выбранному периоду.
- Поиск команд и игроков без перезагрузки страницы.
- Добавление матчей в избранное и удаление из него.
- Восстановление избранного после перезагрузки или повторного открытия сайта.
- Обновление избранного в другой вкладке через событие `storage`.


### Браузерное API

В ДЗ №3 используется **Local Storage API**. В браузере хранится список идентификаторов избранных матчей.

Обработаны недоступность хранилища, ошибки чтения и записи, переполнение квоты, некорректный JSON и неподходящая структура данных. При ошибке сохранения выбор продолжает работать в памяти текущей страницы, а пользователю показывается сообщение.

Избранное сохраняется для конкретного браузера и адреса сайта.

## Локальный запуск

1. Скачайте репозиторий или клонируйте его:

   ```sh
   git clone https://github.com/salomadoma/web_programming_homework.git
   cd web_programming_homework
   git switch hw-3
   ```

2. Откройте папку репозитория в VS Code.
3. Установите расширение **Live Server**.
4. Нажмите правой кнопкой на `hw-1/index.html` и выберите **Open with Live Server**.
5. Переходите между экранами через меню приложения.

## Проверка сохранения избранного

1. Откройте страницу «Матчи» и добавьте несколько игр в избранное.
2. На главной проверьте блок «Избранные матчи».
3. Обновите страницу — список должен сохраниться.
4. Удалите матч или очистите весь список.
